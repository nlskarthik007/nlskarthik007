> **[RL_buggy_2.0](https://github.com/nlskarthik007/RL_buggy_2.0)** <br/>
> *Next-generation multi-terrain autonomous navigation in MuJoCo powered by `UnifiedBuggyEnv`, a 16-ray planar LIDAR suite, Unified DAgger imitation warmstart, and RecurrentPPO (LSTM) fine-tuning. A single generalist policy adapts zero-shot across orthogonal mazes (`ortho_maze`), sweeping curves (`curve_track`), obstacle fields (`open_arena`), and composite arenas (`hybrid_arena`).* <br/>
> 💡 **Benchmarks:** `95.0% Multi-Terrain Generalist (38/40)` | `92.5% Stress Tests (74/80)` | `100% Continuous Euclidean (50/50)` | `98.6% Unseen Curves (142/144)`
>
> **[RL_Maze_Buggy](https://github.com/nlskarthik007/RL_Maze_Buggy)** <br/>
> *Foundational map-free hierarchical RL navigation system pairing RecurrentPPO and Behavior Cloning/DAgger with a Differential PID lookahead controller to solve unseen mazes using sparse 6-ray rangefinders, gyro, and wheel-encoder telemetry.* <br/>
> 💡 **Highlights:** `94% Zero-Collision Success` | `Zero-Shot 5x5 → 7x7 Transfer` | `~341 KB Edge-Ready Footprint`
>
> **[EDITH-Edge-Voice-Activator](https://github.com/byebyewe86-alt/EDITH-Edge-Voice-Activator)** <br/>
> *Offline, ultra-low-latency custom keyword spotting engine running an INT8-quantized Depthwise Separable CNN on ESP32-S3 with I2S audio ingestion via TensorFlow Lite for Microcontrollers.* <br/>
> 💡 **My Contributions:** `ML Engineer: 10+ commits` | Model Architecture, INT8 Quantization, and ESP32-S3 Deployment
>
> **[Innovation-Center-Web](https://github.com/nlskarthik007/IC_web_t2)** <br/>
> *Full-stack research logistics and hardware inventory platform built with React, transactional PostgreSQL via Drizzle ORM, and contract-first tRPC pipelines to streamline lab equipment requisitions and student project governance.* <br/>
> 💡 **My Contributions:** `Core Developer: 40+ commits` | System Architecture, End-to-End Development, Relational Schema Design, and RBAC Operations
>
> **[Pololu-3pi-Arena](https://github.com/nlskarthik007/pololu-3pi-arena)** <br/>
> *Client-server browser robotics simulator and competition arena featuring 120Hz physics, a multi-language JS/Python code editor, Visual Track Designer, Organizer Lock Mode, and real-time SSE leaderboard sync backed by Node.js and PostgreSQL.* <br/>
> 💡 **Highlights:** `120Hz Physics Engine` | `Live SSE Competition Sync` | `Full-Stack TypeScript + PostgreSQL`
